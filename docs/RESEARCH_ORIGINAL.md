# 원작 "Steal An Egg" 재조사 메모 (2026-10-18, 본부장)

사장님 지적: 지금 우리 게임은 구조가 원작과 다르고(브레인로트 훔치기식 흩어진 구역), 퀄리티가 낮고, 낮이 너무 길고, 경비를 따돌리는 긴장감이 없고, 러닝머신도 다르다. **원작을 그대로 따라 만든다.**

## 1. 확인된 사실 (공식 페이지·위키·영상 프레임)
- 공식: Steal An Egg, 제작 그룹 "and Collect Rare Pets", 2026-07-25 출시, 최대 7명, 장르 Simulation/Tycoon, 동접 174만(10-18 기준), 방문 86억.
- 공식 설명 순서: 펫에게서 알 훔치기 → 부화 → 펫이 돈 벌기 → 러닝머신·베이스 업그레이드 → 러닝머신으로 속도 훈련 → **다른 플레이어에게서 알 훔치기**.
- **맵은 한 줄(사다리) 구조.** 구역은 고정 순서로 멀어질수록 다음 구역. "벚꽃에서 잡히면 심연의 바다 쪽으로 밀려난다", "집에 가까운 구역(바로 다음 구역이어도)에서 잡히면 알이 그 자리에 남는다" → 먼 구역에서 돌아올 때 **앞 구역들을 차례로 통과**한다. 구역 사이에 문(gate)은 없다.
- 영상 프레임(한국 유튜버 플레이): 바닥은 **밝은 초록 스터드(클래식 베이스플레이트)**, 구역/맵 경계는 **갈색 벽돌 담장**(높은 벽), 베이스는 **나무 울타리**로 둘러싸인 잔디밭, 펫들이 베이스 잔디 위에 서 있고 머리 위에 **"+$8", "+$37" 돈 팝업**이 뜬다. 베이스 안에 핑크 선베드 등 장식. HUD: 왼쪽 세로 버튼(상점·인덱스…), 왼쪽 아래 신발 아이콘+속도, 그 아래 돈, 오른쪽에 알/아이템 아이콘, 오른쪽 아래 큰 노란 둥근 버튼.
- 경비: 구역마다 1마리, 둥지 길목에 있음. 알을 들면 추격 시작, 잡히면 래그돌로 **구역 밖으로** 튕겨 나감. 추천 속도의 약 2배가 안전. 일부 경비는 **잠들어 있을 때**(호수 등) 몰래 가능.
- 주기: 알 리셋 5분 + 13초 닫힘. 낮/밤 약 4.5분(출처 1개). 밤에는 훔치기 불가, 알 30배 성장. (사장님 체감: 낮이 너무 길다 → 원작 실제 값 확인 필요)
- 러닝머신: 베이스 앞에 있음. 올라서면 **입력 없이** 매초/걸음마다 속도가 쌓임. 레벨마다 이름이 다름: 기본 → Sci-Fi($15K, +5) → Flame($250K, +12) → Celebrity($5M, +30) → Golden($120M, +80) → Freeze($3B, +100) → Lucky Block($75B, +200) → Hacker($2T, +500) → Demonic($50T, +1,000) → Angelic($1Qa, +2,000). 관리자 이벤트용 **거대 러닝머신**도 있음(여러 명이 함께 탐).
- 베이스 업그레이드 첫 단계: 정원 $1,000 → 러닝머신 해금. 알은 베이스에서 각각 타이머로 자라고 **직접 열어야** 함. 퓨즈 머신·트레일 상점(안전 구역 오른쪽)·무료 상자.

## 2. 아직 모르는 것 (사장님께 확인)
1. 베이스 7개가 길의 어디에 있는지(양옆? 시작점에 모여?), 스폰 위치.
2. 구역 사이 경계가 어떻게 생겼는지(벽돌 담장에 입구? 표지판?), 구역 하나의 폭·길이 느낌.
3. 러닝머신에서 정확히 뭐가 다른지(걸음 게이지? 자동 달리기 애니메이션? 시간 제한? 버튼?).
4. 낮/밤 길이 체감(원작에서 낮이 몇 분쯤?).
5. 경비를 따돌린 상황(어느 구역, 속도 얼마).
6. 다른 플레이어 베이스의 펫/알을 훔칠 수 있는지, 어떻게(자물쇠?).

## 3. 고칠 방향 (초안)
- 맵: 한 줄 복도. [스폰/안전구역 + 베이스 7개] → 숲 → 호수 → … → 유령 성. 각 구역은 복도 폭 전체를 차지하는 직사각형, 벽돌 담장으로 둘러싸고 앞뒤로 트인 길. 뒤 구역에서 돌아올 땐 앞 구역 경비 구역을 지나감.
- 비주얼: 클래식 스터드 바닥·벽돌 담장·나무 울타리·밝은 채도. 펫은 파트 수를 늘려 원작처럼 또렷한 실루엣. 돈 팝업 "+$n".
- 경비: 추격 포기 거리 없음(안전 구역까지). 속도 모자라면 반드시 잡히는 비율(경비 속도 = 플레이어 속도 × max(1.15, 추천/내속도 비율)). 일부 경비 "잠듦" 상태.
- 시간: 사장님 확인 후 조정(예: 낮 2~3분).
- 러닝머신: 레벨마다 이름·모양 다르게, 사장님 설명대로 동작.
