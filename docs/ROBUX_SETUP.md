# 로벅스 상품 만들기 — 아빠(보호자)용 안내

"씨앗을 훔치세요"에는 로벅스로 사는 것이 **37개** 있습니다. 사장님 결정(2026-11-10)대로 두 종류로 나뉩니다:
**영원히 가지는 것 = 게임패스 12개**, **쓰면 없어지는 것(소모품) = 개발자 상품 25개**.
게임 코드는 다 되어 있고, 로블록스 쪽에서 패스·상품을 **만들어서 그 번호(id)만 붙여 넣으면** 살 수 있게 됩니다.
번호를 붙이기 전에는 게임 화면에 **"준비 중"** 이라고 나오고, 아무것도 살 수 없습니다.

> 진짜 돈이 드는 일이라 **보호자께서 직접** 해 주세요. 아이 혼자 하지 않도록 해 주세요.

---

## 1. 순서 (한 번만 하면 됨)

1. **게임 게시하기**
   로블록스 스튜디오에서 게임을 열고 **File → Publish to Roblox** (또는 "Roblox에 게시").
   이미 게시했다면 건너뛰세요.
2. **Creator Dashboard 열기**
   웹 브라우저로 로블록스에 로그인 → **Creator Dashboard (create.roblox.com)** → **Creations** → 이 게임 선택.
3. **게임패스 12개 만들기** (3장 첫 번째 표)
   왼쪽 메뉴 **Monetization → Passes** → **Create a Pass**. 만든 뒤 각 패스를 **판매 중(On Sale)** 으로 하고
   **가격(로벅스)을 표와 똑같이** 넣어 주세요. 이름·설명·그림은 자유입니다.
4. **개발자 상품 25개 만들기** (3장 두 번째 표)
   왼쪽 메뉴 **Monetization → Developer Products** → **Create a Developer Product**. 가격은 표와 똑같이.
   (게임 버튼에 표의 가격이 보이기 때문에, 다르면 아이가 헷갈립니다.)
5. **번호(id) 복사해서 붙이기**
   게임패스는 **Pass ID**, 개발자 상품은 **Product ID**(숫자)를 복사해서, 저장소의 `src/shared/Data/Products.luau` 파일 안
   `local IDS = { ... }` 에서 그 key 오른쪽 `0` 을 그 숫자로 바꿉니다. 한 표 안에 `[게임패스]` · `[개발자 상품]` 주석으로 나뉘어 있습니다.

   ```lua
   boost_2 = 0,          -- 바꾸기 전
   boost_2 = 1234567890, -- 바꾼 뒤 (예시 숫자 — boost_2 는 게임패스라 Pass ID)
   ```

   37칸을 다 채우지 않아도 됩니다 — 채운 것만 살 수 있고, 나머지는 계속 "준비 중"입니다.
   잘 모르겠으면 id 목록을 본부장(Claude)에게 알려 주시면 대신 붙여 넣습니다.
6. **스튜디오에서 시험해 보기**
   스튜디오에서 플레이하면 구매창이 떠도 **테스트 구매라 진짜 로벅스가 나가지 않습니다** (무료).
   번호 없이도 시험하려면 채팅에 개발 명령 `/buy boost_8` 처럼 치면 바로 받아집니다 (스튜디오에서만 됨).
7. **게임 다시 게시하기** — 번호를 붙인 코드를 다시 Publish 해야 실제 게임에 반영됩니다.

## 1-1. 아빠가 꼭 알아야 할 것 (테스트 담당 주임 검수, 2026-11-10 · 게임패스 나누기 2026-11-10)

1. **id 는 하나에 하나씩, 가격까지 아래 표와 똑같이.** 다른 것의 id 를 붙이면 산 사람에게 엉뚱한 것이 가고
   되돌릴 수 없습니다. **처음엔 한두 개만** 붙여서 스튜디오 테스트 구매(무료)로 맞게 받아지는지 본 뒤, 나머지를 붙이세요.
2. **패스 id 와 상품 id 를 섞지 마세요.** 게임패스 12개 칸(`boost_*` · `money_pass`)에는 **Passes** 화면의 Pass ID 를,
   개발자 상품 25개 칸(`tskip_*` · `coins_*` · `speed_*` · `seed_super`)에는 **Developer Products** 화면의 Product ID 를 붙입니다.
   바꿔 붙이면 구매창이 안 뜨거나 산 것이 안 들어옵니다.
3. **`src/shared/Data/Config.luau` 의 `DEV_USER_IDS` 는 비워 두세요** (`{}`). 여기에 번호를 넣으면 그 사람은
   실제 게임에서도 개발 명령 `/buy` 로 상품을 **공짜로** 받을 수 있습니다.
4. **id 를 붙인 뒤에는 꼭 검사하고 게시**: 저장소 폴더에서 `lune run tests/run.luau` 를 돌려 실패가 0 인지 확인한 다음
   스튜디오에서 다시 Publish 하세요. (검사가 어려우면 본부장(Claude)에게 "id 붙였어, 검사해 줘" 라고 하면 됩니다.)

   (주임이 찾은 "러닝머신 레벨 상품을 싼 것으로 여러 번 사서 비싼 레벨을 얻는 구멍"(F-3)은 수석이 고쳤습니다 —
   레벨이 안 맞게 산 상품은 **낸 로벅스만큼만** 레벨·속도로 줍니다.)

## 2. 꼭 확인해 주세요 (보호자)

- **나이·계정 규정**: 로블록스는 나이(13세 미만 계정 등)·본인 인증에 따라 상품 판매나 수익 기능을
  막아 두는 경우가 있고, 규정이 자주 바뀝니다. **Creator Dashboard 화면과 로블록스 도움말에서 직접 확인**해 주세요.
  필요하면 보호자 계정(또는 그룹)으로 게임을 게시하는 방법도 있습니다.
- **수익 지급(DevEx 등)**: 받은 로벅스를 현금으로 바꾸는 것은 따로 조건(나이·인증·최소 금액 등)이 있습니다.
  이것도 보호자께서 로블록스 안내를 직접 보고 정해 주세요.
- **가격**: 아래 표는 사장님(아이)이 정한 가격입니다. 18 ~ 20레벨 세 개(12,000 · 15,000 · 20,000)는 "끝까지 쭉"이라는
  말씀만 있어서 개발팀이 추정한 값입니다 — 바꾸고 싶으면 Creator Dashboard 가격과
  `src/shared/Data/Products.luau` 의 `TREADMILL_SKIP_ROBUX` 를 **같이** 바꿔 주세요.
- **개발자 상품의 환불·중복**: 서버가 영수증 번호를 기억해서 같은 구매를 두 번 주지 않고, 게임이 지급을 끝내지 못한 구매는
  로블록스가 나중에 다시 알려 줍니다 (서버 `ProductService`).
- **게임패스는 영수증이 없습니다**: 서버가 접속할 때와 산 직후에 로블록스에 "이 사람이 이 패스를 가졌나"를 물어서 줍니다.
  게임 밖(게임 페이지 상점)에서 산 패스는 그 서버에서 바로 안 보일 수 있고, **다시 접속하면** 들어옵니다.

## 3. 상품 표 (37개) — Creator Dashboard 에 만들 것

### 게임패스 12개 — Monetization → **Passes** (영원히, 한 번만 삼)

**부스트 11개는 2배부터 차례로 전부 Pass ID 를 붙여 주세요** — 2배 id 가 비어 있으면 게임 안에서 아무도 4배 이상을 살 수 없습니다.
러닝머신에서 오르는 속도가 그 배수만큼. **순서대로만 열립니다** — 2배를 사야 4배, 4배를 사야 8배 버튼이 열립니다
(사장님 2026-11-10). 그래서 2048배까지 가려면 11개를 다 사야 하고 합계는 **4,094 로벅스**입니다. 곱해지지 않고 가장 큰 것 하나만 적용됩니다.
게임패스는 게임 페이지(웹) 상점에서도 살 수 있어서 **순서를 건너뛰어 비싼 배수만 살 수 있는데**, 그러면 **낸 값만큼만** 받습니다
(가진 패스 가격 합으로 2배부터 차례로 — 예: 2048배 패스만 사면 1024배, 4배 패스만 사면 2배. 앞의 배수 패스를 사면 올라갑니다).

| `boost_4` | 러닝머신 부스트 x4 | 4 |
| `boost_8` | 러닝머신 부스트 x8 | 8 |
