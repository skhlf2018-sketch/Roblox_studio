# 씨앗을 훔치세요 — 설계 초안 (6판, 사장님 아이디어, 2026-10-27)

> 상태: **초안**. 사장님이 2026-10-27 에 말씀하신 것과 본부장이 제안한 "정원 키우기" 아이디어를 합쳐 정리한 것.
> 아직 코드는 안 만듦. 아래 "사장님이 정할 것" 5개에 답이 오면 GAME_DESIGN 6판으로 확정하고 시작.
> 계란 훔치기(5판)를 사장님만의 게임으로 바꾸는 작업이며, 유명 게임의 이름·캐릭터·그림·소리는 안 가져오고 **노는 방법만** 가져옴.

## 1. 한 줄 설명
구역 깊숙이 들어가 **씨앗을 훔쳐** 안전 구역으로 달려오고, 내 **정원**에 심어 새싹 → 식물 → **성체**까지 키워 코인을 벌고 도감을 채우는 게임.

## 5. 정원 키우기 (본부장 제안, 사장님 "추가")

- 성체 식물은 가끔 **열매**를 떨어뜨림(등급 높을수록 좋은 열매). 열매는 코인으로 팔거나, 다른 식물에 **먹이면 돌연변이**(황금·무지개·얼음·불 …)가 됨 → 코인 생산 배율 ↑, 도감에 돌연변이 칸.
- 밤에는 성체까지 가는 시간도 30배 빨라짐(지금 밤 규칙 그대로).
- 정원에서 할 일이 생겨서 씨앗 훔치러 안 나갈 때도 심심하지 않음.
- 물 주기(지금 쓰다듬기): 식물 앞에서 F → 하트 대신 물방울, 성장 시간 10초 줄어듦(쿨다운 1분, 선택).

## 6. 씨앗의 모양·아우라
- 씨앗: 작은 타원(지금 알 모양 재사용) + 등급 색 + 아우라 파티클(3장 표). 특별 씨앗(비밀 이상)은 빛기둥·이름표(500 스터드 안).
- 자라는 모습: 새싹(0~25%) → 줄기+잎(25~60%) → 봉오리(60~99%) → 성체(100%, 식물마다 다른 모양·열매). 성체 위에 코인/초 표시.
- 식물 종류: 134종(지금 펫 수만큼) — 이름·모양은 **우리가 새로 지음** (사장님 아이디어 환영: 예 "불꽃 해바라기", "얼음 선인장", "별 버섯").

## 7. 사장님이 정할 것 (답이 오면 확정)
1. 성체 식물은 **코인을 계속 만드나요**(지금 펫 수입처럼), 아니면 **열매를 따서 팔아야** 하나요? (본부장 제안: 둘 다 — 코인은 자동, 열매는 가끔)
2. "코인"은 **게임 안 돈**(무료) 맞죠? 로벅스로 건너뛰기는 어른 확인이 필요해서 나중에.
3. 밤 30배 그대로 두나요?
4. 퓨전 머신·사쿠라 나무·제단은 어떻게 할까요? (제안: 퓨전 → "교배 머신"(식물 2개 → 새 식물), 사쿠라·제단은 뺌)
5. 경비는 지금처럼 동물로 두나요, 식물 괴물(식충 식물·가시 덩굴 …)로 바꿀까요?
