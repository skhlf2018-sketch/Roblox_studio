# 사장님 체크리스트: 스튜디오에서 "씨앗을 훔치세요" 시험하기 (6판)

사장님, 이 종이는 **"게임이 진짜로 잘 돌아가는지" 눈으로 확인하는 숙제**예요.
컴퓨터가 알아서 해 본 시험(456개 + 화면 모양 시험 2종)은 이미 끝났어요. 그런데 **보이는 것, 들리는 것, 걸어 다니는 느낌**은 사장님 눈으로만 알 수 있어요.

- 하나씩 해 보고, 잘 되면 `[ ]` 안에 `x` 를 적어요. (`[x]`)
- 이상하면 **그 번호**를 적어 두고, 맨 아래 "고장 보고 방법"대로 보내 주세요.
- 한 번에 다 안 해도 돼요. **1번부터 15번까지가 이번 6판의 핵심**이에요 (씨앗 줍기 → 심기 → 자라기 → 성체 → 열매 → 팔기 → 먹이기 → 건너뛰기 → 물 주기 → 사쿠라 → 도감 → 러닝머신).
- 막히면 어른(본부장)에게 물어봐도 돼요.

---

## 1부. 준비하기 (딱 4단계)

**1단계. 로블록스 스튜디오를 켜요.**

**2단계. 게임 파일을 열어요.**
- 왼쪽 위 **File(파일)** → **Open from File(파일에서 열기)**
- 이 파일을 골라요: `D:\준수\RobloxST\Roblox_studio\build\StealAnEgg.rbxl` (파일 이름은 옛날 그대로예요)
- (본부장에게: 새 코드를 합친 뒤 `rojo build default.project.json -o build/StealAnEgg.rbxl` 로 파일을 새로 만들어 주세요. 옛날 파일이면 시험이 소용없어요.)

**3단계. 글자 창(Output)을 켜요.**
- 위쪽 **View(보기)** 탭 → **Output(출력)**. **빨간 글자는 고장 신호**, 노란 글자는 주의예요.

**4단계. 게임을 시작해요.**
- **Home(홈)** 탭 → 초록 삼각형 **Play(플레이)** (또는 **F5**). 처음에는 10~30초쯤 걸려요(맵이 커요).
- 끝낼 때는 빨간 네모 **Stop(정지)** 또는 **Shift + F5**.

## 2부. 치트키 (개발 명령) 알아 두기

**채팅창**(키보드 **/**)에 쓰고 Enter. 성공하면 "[개발] /coins 1e9" 같은 파란 알림이 떠요. **스튜디오에서만** 돼요.

| 명령 | 하는 일 | 예시 |
|---|---|---|
| `/coins 숫자` (`/money` 도 같음) | 코인을 받아요 | `/coins 1e9` |
| `/speed 숫자` | 속도를 받아요 | `/speed 1e9` |
| `/seed 식물id` | 그 식물의 **씨앗을 가방에** 바로 넣어요 | `/seed puppy_grass` (강아지풀, **3초면 성체**) |
| `/plant 식물id 개수` | 정원 빈자리에 **성체를 바로** 심어요 (열매 1개 달림) | `/plant owl_oak 2` |
| `/fruit 개수 [식물id]` | 열매 가방에 열매를 받아요 | `/fruit 20 moon_lotus` |
| `/grow` | 정원에서 자라는 씨앗을 **전부 성체로** | `/grow` |
| `/skip` | 낮 → 밤 → 씨앗 초기화 → 낮을 **한 칸씩 넘겨요** | `/skip` |
| `/trap 숫자` | 곰덫을 받아요 | `/trap 5` |
| `/crystal 숫자` | 사쿠라 크리스탈을 받아요 | `/crystal 20` |
| `/zone 구역` | 그 구역 입구로 순간이동 (`hub` = 허브) | `/zone cherry_blossom`, `/zone 10` |
| `/tutorial reset` | 튜토리얼을 1단계부터 다시 (500 코인 다시 받음) | `/tutorial reset` |

**숫자 쓰는 법:** `1e3` = 천, `1e6` = 백만, `1e9` = 10억, `1e12` = 1조.
**식물 id 예:** `sprout_daisy`(아기 데이지·일반) · `puppy_grass`(강아지풀·일반 3초) · `owl_oak`(부엉이 참나무·희귀) · `moon_lotus`(달빛 연꽃·희귀) · `crystal_snowdrop`(수정 설강화·전설) · `star_mushroom`(별 버섯·전설) · `galaxy_tree`(은하수 나무·코스믹) · `sky_pillar_flower`(하늘 기둥꽃·슈퍼 울트라디바인)

> 명령이 아무 반응이 없으면 **그게 첫 번째 고장**이에요. 번호와 함께 알려 주세요.

## 3부. 확인할 것 (1~15번 = 6판 핵심 순서, 16번부터 = 원래 있던 것)

### 가. 6판 핵심: 씨앗 → 정원 → 열매 (1~15번)

- [ ] **1. 켜자마자 괜찮나요?**
  - 정상: Output 에 빨간 글자가 없고, `[씨앗을 훔치세요] 클라이언트 시작 완료` 가 보여요. 허브 안 내 베이스 앞에서 시작하고, 허브 파란 판에 **"씨앗을 훔치세요"** 가 쓰여 있어요.
  - 왼쪽 아래에 **속도**와 **"0 코인"**, 오른쪽에 빨간 **씨앗** 버튼 · 주황 **식물(정원)** 버튼 · 초록 **열매** 버튼(배지 "0/300")이 있어요. 화면 어디에도 **"$"·"알"·"펫"·"부화"** 글자가 없어야 해요.

- [ ] **2. 씨앗을 주울 수 있나요?**
  - 해 보기: 숲(첫 구역)의 둥지 위 **씨앗**(아몬드 모양, 등급 색 줄무늬) 옆에서 **E**.
  - 정상: 씨앗이 머리 위로 올라가고 빨간 **달리기!!** 와 식물 괴물 이름("덥석 파리지옥")이 떠요.
  - 또 보기: 숲 가운데 경비가 **파리지옥 식물 괴물** 모양이에요. 잘 때는 눈을 감고 **Z** 가 떠요. 쫓아올 때만 눈을 뜨고 **화난 눈썹**이 보여요.

- [ ] **3. 안전 구역에 들어오면 가방에 들어가나요?**
  - 해 보기: 씨앗을 들고 허브(바닥에 "안전 구역" 글씨가 있는 선 안쪽)로 달려와요. (느리면 `/speed 1e9`)
  - 정상: 성공 알림과 함께 씨앗이 **아래 핫바의 씨앗 칸**과 오른쪽 **씨앗 버튼 창(가방)** 에 생겨요.

- [ ] **4. 정원에 심을 수 있나요?**
  - 해 보기: 핫바의 씨앗 칸을 누르고, 내 베이스 뒤쪽 **정원**(울타리 안 잔디) 바닥을 클릭/터치해요.
  - 정상: 미리보기가 초록(심을 수 있음)/빨강(안 됨)으로 보이고, 누른 자리에 씨앗이 **흙에 반쯤 묻혀** 심겨요. 다른 씨앗·식물과 너무 가까우면 빨강이에요.
  - 씨앗 창 위에 "정원 n / 칸 수"(자라는 씨앗 + 성체)가 맞게 늘어요.

- [ ] **5. 단계마다 모양이 바뀌나요?**
  - 해 보기: `/seed owl_oak` 로 희귀 씨앗을 심고 지켜봐요. (오래 걸리면 밤에 30배 빨라요: `/skip`)
  - 정상: **씨앗(묻힘) → 새싹 → 줄기 + 잎 → 봉오리(등급 색)** 로 모양이 바뀌어요. 씨앗 창의 단계 이름(새싹·줄기·봉오리)과 남은 시간이 맞아요.
  - 희귀(rare) 이상은 **둘레에 아우라**(파랑 반짝·보라 불꽃·금빛 링…)가 보여요. **100칸 넘게 멀어지면 꺼지고** 다시 오면 켜져야 해요.

- [ ] **6. 성체가 되나요?**
  - 해 보기: `/seed puppy_grass` 를 심고 3초 기다려요 (또는 아무 씨앗이나 심고 `/grow`).
  - 정상: 그 자리에서 **성체 식물**로 바뀌고 **"성체가 됐어요!"** 카드가 떠요 (열매 1개 값 · 몇 초마다). 처음 만난 식물이면 **NEW! / 도감 새 발견!**.
  - 식물이 구역마다 다르게 생겼고(숲 꽃·사막 선인장·바다 수초…), 가까이 가면 **살랑살랑** 흔들려요. 이름표가 식물 위에 떠요.

- [ ] **7. 열매가 맺히고 딸 수 있나요?**
  - 해 보기: 성체 앞에서 **E "열매 따기"**. 또는 주황 **식물 버튼** → **열매 모두 따기**.
  - 정상: 식물에 달린 열매가 사라지고 그 위에 **"+열매 N"** 팝업 + 뽁 소리. 오른쪽 열매 배지 숫자가 올라요. 시간이 지나면 열매가 **하나씩 다시 달려요**(최대 5개, 5개면 멈춤). 열매가 없으면 E 가 안 떠요.

- [ ] **8. 열매를 팔 수 있나요?**
  - 해 보기: 내 베이스 또는 허브의 **판매 가판대** 앞에서 **E "열매 팔기 (열매 N개 · N 코인)"**.
  - 정상: **"+N 코인"** 이 크게 뜨고 짤랑 소리, 코인이 늘고 열매 배지가 0 이 돼요. 열매가 없으면 "열매가 없어요" 안내만 떠요.
  - 같은 가판대의 **F "식물 팔기"** 또는 정원 식물 창 카드의 **팔기** → 확인 창 → 성체가 사라지고 코인을 받아요 (열매 값 × 20).

- [ ] **9. 열매를 먹일 수 있나요?**
  - 해 보기: `/fruit 20`. 초록 **열매 버튼** → 열매 칸의 **먹이기** → 성체 고르기 (카드에 확률이 보여요) → 확인.
  - 정상: 붙으면 반짝 + "얼음!"·"황금!" 같은 이름, 식물 색이 바뀌어요. 안 붙으면 **"냠냠"**. 더 붙을 게 없는 식물은 회색이라 못 골라요.

- [ ] **10. 코인으로 건너뛸 수 있나요?**
  - 해 보기: `/coins 1e9`. 희귀 이상 씨앗을 심고, 씨앗 창 줄의 **⏩** 또는 씨앗 앞 **R "건너뛰기"** → **전부 · N 코인** / **절반 · N 코인** 을 눌러요.
  - 정상: 확인 창이 뜨고, 가격이 **1초마다 조금씩 줄어요**. 전부 = 바로 성체, 절반 = 남은 시간 절반. 코인이 모자라면 버튼이 **회색**이에요.
- [x] **11. 물 주기는 없어요** — 사장님 지시(2026-10-28)로 뺐어요. 씨앗·성체 앞에서 **"물 주기" 프롬프트가 안 떠야** 정상이에요.
  - 친구와 같이 하면: 친구가 물을 줄 때 **내 화면에도** 그 식물에 물방울이 보여요. 남의 식물에는 내 프롬프트가 안 떠요.

- [ ] **12. 사쿠라 나무가 되나요?**
  - 해 보기: `/plant sprout_daisy 2`, `/crystal 20`, `/zone 10`. 벚꽃 구역(10번째)의 **분홍 벚꽃 나무**(꽃잎이 날림) 앞에서 **E**.
  - 정상: 창에 버튼 2개 — **성체 바치기**(성체를 고르면 카드에 받을 크리스탈 수 → 그 성체가 사라지고 크리스탈 +) / **씨앗 뽑기 · 크리스탈 10**(모자라면 회색 → 벚꽃 씨앗이 가방에).

- [ ] **13. 도감이 6판인가요?**
  - 해 보기: 왼쪽 **도감** 버튼.
  - 정상: 제목 "식물 도감", 등급이 **11개**(맨 위 영원·신성·**슈퍼 울트라디바인**, 신성 이상은 무지개 띠). 발견한 식물은 **식물 모양**으로, 모르는 건 검은 실루엣. "열매 1개 N 코인 · N초마다" 글, **받기!** 를 누르면 속도·코인이 늘어요.

- [ ] **14. 러닝머신이 20레벨까지 되나요?**
  - 해 보기: `/coins 1e30` 을 몇 번 쓰고 **상점 → 러닝머신**을 끝까지 사요.
  - 정상: 카드에 "○○ 러닝머신: **1초에 속도 +N**", 11~20레벨 이름(정글·바다·사탕·벚꽃·용암·수정·유령·은하·무지개·황제)과 베이스의 **러닝머신 모양**이 레벨마다 바뀌어요. 20레벨에서 올라서면 **"+1M"** 분홍 팝업이 1초마다 떠요.

- [ ] **15. 정원 업그레이드가 되나요?**
  - 해 보기: 상점 → **정원 업그레이드**.
  - 정상: "정원 칸 7 → 8" 처럼 칸 수가 보이고, 사면 씨앗 창의 "정원 n / 칸 수" 가 늘어요. 칸이 가득 차면 심을 때 "정원이 가득 찼어요" 알림.

### 나. 원래 있던 것 (16~30번)

- [ ] **16. 경비가 쫓아오고 잡히나요?** — 씨앗을 들고 가만히 있으면 식물 괴물이 걸어와요(화면에 거리). 구역 안에서 잡히면 날아가고 씨앗은 **둥지로**, 구역 밖에서 잡히면 씨앗이 **그 자리에 떨어져요**(60초 뒤 사라짐). 경비가 땅에 박히거나 안 보이면 꼭 알려 주세요.
- [ ] **17. 15개 구역 경비가 다 식물 괴물인가요?** — `/zone 2` ~ `/zone 15` 로 가 봐요: 연꽃 개구리풀 · 가시 선인장 대장 · 덩굴 호랑이꽃 · 서리 가시나무 · 용암 머리꽃 · 심해 해초 괴물 · 공룡 고사리 · 우주 버섯 거인 · 벚꽃 여우나무 · 돌 거인 나무 · 천사 백합(주기마다 악마 장미로 바뀜) · 정령 버섯 · 사탕수수 거인 · 호박 머리 덩굴. 둥지 옆에 그 구역 **작은 장식 식물**도 있어요.
- [ ] **18. 밤이 오나요?** — `/skip` 한 번: 화면이 어두워지고 "밤" 띠, 자라는 씨앗 시간이 **30배 빨리** 줄어요. 밤에는 씨앗을 못 훔쳐요. 씨앗을 들고 있으면 내 베이스로 순간이동.
- [ ] **19. 씨앗이 새로 바뀌나요?** — 밤에서 `/skip`: **"ALL SEED RESET!"** 공지, 둥지 씨앗이 새로 놓여요. 가끔 "OO 구역에 OO 씨앗 등장!" 특별 씨앗(빛기둥).
- [ ] **20. 곰덫이 되나요?** — `/trap 5`, 베이스 밖 길에서 곰덫을 들고 눌러요 → 발밑에 놓이고 개수가 줄어요.
- [ ] **21. 튜토리얼이 6판 순서인가요?** — `/tutorial reset`: 위 가운데 "n / 5" 패널. 1 숲에서 씨앗 훔치기(둥지 가리킴) → 2 안전 구역으로 → 3 핫바 씨앗을 정원에 심기(핫바 반짝) → 4 성체까지 기다리기(내 씨앗 가리킴) → 5 열매 따서 팔기(열매 달린 식물 → 열매를 따면 **판매 가판대** 가리킴). 끝나면 색종이 + **500 코인**.
- [ ] **22. 랭킹판이 코인인가요?** — 오른쪽 위 랭킹판 탭이 **코인 / 속도**, 허브 3D 판도 코인. `/coins 1e9` 하고 10초 뒤 내 줄이 올라가요.
- [ ] **23. 상점·트레일이 되나요?** — 트레일을 사면 바로 장착되고 속도 배율이 바뀌어요. 코인이 모자라면 빨간 알림.
- [ ] **24. 폰 화면에서도 괜찮나요?** — Test 탭 장치 에뮬레이터(폰 가로): 버튼이 손가락으로 누르기 충분히 크고, 오른쪽 버튼 3개(씨앗·식물·열매)가 점프 버튼과 **안 겹쳐요**. 확인 창·열매 가방 창이 화면 밖으로 안 나가요.
- [ ] **25. 끊기지 않나요?** — 정원에 식물이 많을 때(`/plant star_mushroom 10`)와 구역 사이를 달릴 때 부드러운지. 심하게 끊기면 어디서인지 알려 주세요.
- [ ] **26. 소리는요?** — 열매 따기(뽁)·팔기(짤랑)·먹이기(냠냠/반짝)·성체(짠)·사쿠라 바치기/뽑기 소리. 설정 창의 음악/효과음 끄기 버튼.
- [ ] **27. 저장이 되나요?** (선택) — 게시 + "API 서비스 접근 허용"을 켠 경우에만 Stop → Play 해도 정원·코인이 남아요. 안 켰으면 사라지는 게 정상.
- [ ] **28. 남의 정원은 못 건드리나요?** (어른과 둘이서) — 다른 사람 식물에는 "열매 따기"가 안 떠요.
- [ ] **29. 씨앗을 다시 주울 수 있나요?** — 자라는 씨앗 앞에서 **E "집기"** (또는 씨앗 창의 가방 버튼)로 **가방에** 되돌리면 자란 만큼 그대로 남아요 (성체는 못 주워요).
- [ ] **30. 슈퍼 울트라디바인 빛기둥** (선택) — `/seed sky_pillar_flower` 를 심으면 하늘로 솟는 빛기둥이 멀리서도 보여요.

## 4부. 고장 보고 방법 (이상한 걸 찾았을 때)

찾으면 **본부장에게 이 틀 그대로** 채워서 보내 주세요. 다 못 채워도 괜찮아요. 아는 것만요.

```
번호: (위의 몇 번 항목이에요? 예: 7번)
무엇을 했나요: (예: 성체 앞에서 E 를 눌렀어요)
어떻게 됐나요: (예: 열매가 안 없어져요)
원래는 어떻게 돼야 하나요: (예: 열매가 가방에 들어가야 해요)
몇 번 해 봤나요: (예: 3번 다 똑같았어요 / 한 번만 그랬어요)
```

그리고 **같이 보내 주면 아주 큰 도움이 되는 것 3가지:**

1. **화면 사진.** 키보드 **Windows + Shift + S** 를 누르고 부분을 끌어서 고르면 복사돼요. 대화창에 **붙여넣기(Ctrl + V)** 하면 돼요.
2. **글자 창(Output)의 빨간 글자.** Output 창에서 마우스 오른쪽 버튼 → **Select All(모두 선택)** → 다시 오른쪽 버튼 → **Copy(복사)**. 대화창에 **붙여넣기** 해요. 빨간 글자가 없어도 "빨간 글자 없음" 이라고 적어 주세요.
3. **컴퓨터인지 폰 에뮬레이터인지.** (폰 모양으로 시험했다면 알려 주세요.)

> 고장은 나쁜 게 아니에요. 사장님이 찾아 주면 고칠 수 있어서 게임이 더 좋아져요. 고마워요!
