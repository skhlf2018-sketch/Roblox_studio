# 사장님 체크리스트: 스튜디오에서 게임 시험하기

사장님, 이 종이는 **"게임이 진짜로 잘 돌아가는지" 눈으로 확인하는 숙제**예요.
컴퓨터가 알아서 해 본 시험(331개)은 이미 끝났어요. 그런데 **보이는 것, 들리는 것, 걸어 다니는 느낌**은 사장님 눈으로만 알 수 있어요.

- 하나씩 해 보고, 잘 되면 `[ ]` 안에 `x` 를 적어요. (`[x]`)
- 이상하면 **그 번호**를 적어 두고, 맨 아래 "고장 보고 방법"대로 보내 주세요.
- 한 번에 다 안 해도 돼요. 1번부터 11번까지가 제일 중요해요.
- 막히면 어른(본부장)에게 물어봐도 돼요.

---

## 1부. 준비하기 (딱 4단계)

**1단계. 로블록스 스튜디오를 켜요.**

**2단계. 게임 파일을 열어요.**
- 왼쪽 위 **File(파일)** → **Open from File(파일에서 열기)**
- 이 파일을 골라요: `D:\준수\RobloxST\Roblox_studio\build\StealAnEgg.rbxl`
- (본부장에게: 새 코드를 합친 뒤 `rojo build default.project.json -o build/StealAnEgg.rbxl` 로 파일을 새로 만들어 주세요. 옛날 파일이면 시험이 소용없어요.)

**3단계. 글자 창(Output)을 켜요.**
- 위쪽 **View(보기)** 탭 → **Output(출력)** 을 눌러요.
- 게임이 하는 말이 여기에 글자로 나와요. **빨간 글자는 고장 신호**예요. 노란 글자는 주의예요.

**4단계. 게임을 시작해요.**
- 위쪽 **Home(홈)** 탭 → 초록 삼각형 **Play(플레이)** (또는 키보드 **F5**).
- 처음에는 10~30초쯤 걸려요. 맵이 아주 커서 만드는 시간이에요. 기다려 주세요.
- 끝낼 때는 빨간 네모 **Stop(정지)** 또는 **Shift + F5**.

---

## 2부. 치트키 (개발 명령) 알아 두기

시험할 때 알을 몇 시간씩 키우면 힘들어요. 그래서 **스튜디오에서만 되는 비밀 명령**이 있어요.
**채팅창**에 쓰고 Enter 를 누르면 돼요. (키보드 **/** 키를 누르면 채팅창이 열려요. 명령은 `/` 로 시작해요.)
성공하면 화면에 "[개발] /money 1e9" 같은 파란 알림이 떠요.

| 명령 | 하는 일 | 예시 |
|---|---|---|
| `/money 숫자` | 돈을 받아요 | `/money 1e9` (10억 원) |
| `/speed 숫자` | 속도를 받아요 (빨라져요) | `/speed 1e9` |
| `/skip` | 낮 → 밤 → 알 초기화 → 낮 순서로 **한 칸씩 넘겨요** | `/skip` |
| `/grow` | 우리에 놓은 알을 **전부 다 키워요** | `/grow` |
| `/egg 펫이름` | 그 펫의 알을 **가방에 바로** 넣어요 (우리에 놓아 보기용) | `/egg axolotl` |
| `/trap 숫자` | 곰덫을 받아요 | `/trap 5` |
| `/crystal 숫자` | 사쿠라 크리스탈을 받아요 | `/crystal 5` |
| `/pet 이름 개수` | 펫을 바로 받아요 (1~20마리) | `/pet chicken 3` |
| `/quests` | 마법의 숲 퀘스트를 **전부 끝내요** | `/quests` |

**숫자 쓰는 법:** `1e3` = 천, `1e6` = 백만, `1e9` = 10억, `1e12` = 1조.
**펫 이름은 영어예요:** `chicken`(닭) · `crane`(학) · `pegasus`(페가수스) · `skeleton_horse`(스켈레톤 말)

> 명령이 아무 반응이 없으면 **그게 첫 번째 고장**이에요. 3번 항목으로 가서 번호와 함께 알려 주세요.

## 3부. 확인할 것 30가지

### 가. 켜자마자 (1~5번)

- [ ] **1. 글자 창에 빨간 글자가 없나요?**
  - 보기: Output 창을 쭉 훑어봐요.
  - 정상: 빨간 글자가 없고, `[DevCommands] 개발 명령 켜짐` 과 `[StealAnEgg] 클라이언트 시작 완료` 가 보여요.
  - 빨간 글자가 있으면: 그 글자를 **통째로 복사**해서 보내 주세요. (제일 중요한 증거예요!)

- [ ] **2. 내 베이스(울타리 있는 내 땅)에서 시작하나요?**
  - 정상: 울타리 안에 서 있고, 입구 위에 "내 이름의 베이스" 표지판이 있어요. 땅에 초록색으로 빛나는 동그라미(배달 패드)가 보여요.

- [ ] **3. 화면 위에 돈, 속도, 시간이 보이나요?**
  - 정상: 위쪽에 돈($0), 속도, 노란 "낮 4:45" 같은 시계가 있어요. 시계는 줄어들어요.

- [ ] **4. 왼쪽 버튼 6개가 눌리나요?**
  - 해 보기: 도감, 선물, 상점, 펫, 설정, 퀘스트 버튼을 **하나씩** 눌러요. 창이 열리면 **ESC** 키나 X 로 닫아요.
  - 정상: 창이 부드럽게 열리고 닫혀요. 글자가 네모(□)로 깨지지 않아요.

- [ ] **5. 오른쪽 아래에 도구 버튼이 있나요?**
  - 정상: 방망이 그림 버튼이 있어요. 키보드 **1** 을 누르면 방망이를 손에 들어요.

### 나. 돈 쓰기 (6~8번)

- [ ] **6. 돈 명령이 되나요?** (이게 안 되면 아래 숙제를 못 해요. 꼭 확인!)
  - 해 보기: 채팅에 `/money 1e9` 를 쓰고 Enter.
  - 정상: 위쪽 돈 숫자가 드르륵 올라가고 "[개발] /money 1e9" 알림이 떠요.

- [ ] **7. 상점에서 물건을 살 수 있나요?**
  - 해 보기: 왼쪽 **상점** 버튼 → 우리(Pen), 러닝머신, 트레일을 사 봐요.
  - 정상: 돈이 줄어들고, 사면 초록색 알림이 떠요. 돈이 모자라면 빨간 "돈이 부족해요!" 알림이 떠요.

- [ ] **8. 러닝머신이 속도를 올려 주나요?**
  - 해 보기: 내 베이스에 있는 **검은 벨트(러닝머신)** 위에 올라서 있어 봐요.
  - 정상: 위쪽 **속도 숫자가 조금씩 올라요**.

### 다. 알 훔치기: 게임의 진짜 재미 (9~16번)

- [ ] **9. 구역 표지판이 보이나요?**
  - 해 보기: 베이스 앞문으로 나가서 길을 따라 걸어요. 큰 아치 "계란 훔치기"를 지나서 쭉 가면, 길 **왼쪽**에 첫 번째 구역 **숲**이 나와요.
  - 정상: 입구에 큰 글자로 구역 이름, 작은 글자로 "추천 속도"가 있어요. 구역 바닥 색이 달라요.

- [ ] **10. 알을 훔칠 수 있나요?**
  - 해 보기: 숲 안의 **갈색 둥지 위 알** 옆으로 가요. 알 이름표가 보이면 키보드 **E** 를 눌러요. (폰은 화면에 뜬 버튼을 눌러요.)
  - 정상: 알이 **내 머리 위로** 올라가고, 화면에 빨간 **RUN!!** 과 경비 이름("닭")이 떠요. 알을 들면 조금 느려져요.

- [ ] **11. 경비가 쫓아오나요?** (제일 중요해요!)
  - 해 보기: 알을 들고 가만히 서서 경비를 봐요. 숲 가운데 있는 경비는 닭 모양에 머리 위 이름표가 있어요.
  - 정상: 경비가 **걸어서 나를 쫓아와요**. 화면에 경비까지 거리(예: "닭까지 23m")가 보여요.
  - 이러면 고장: 경비가 **안 보이거나, 깜빡거리거나, 땅에 박혀서 안 움직이거나, 이름표만 떠 있어요**. 그런 경우 알을 들어도 아무 일이 없어요. 반드시 알려 주세요! (그때 Output 창도 같이 복사해 주세요.)
  - 또 이러면 알려 주세요: 경비가 나무나 바위에 **걸려서 멈춰 있어요**.

- [ ] **12. 숲 안에서 잡히면 어떻게 되나요?**
  - 해 보기: 알을 들고 **숲 안에서** 가만히 서 있어요. 경비가 와서 닿게 해요.
  - 정상: 화면이 흔들리고 빨간색이 번쩍하며 "잡혔다!"가 떠요. 내 캐릭터가 뒤로 날아가 잠깐(약 2.5초) 못 움직여요. **알은 원래 둥지로 돌아가요.**

- [ ] **13. 숲 밖에서 잡히면 어떻게 되나요?**
  - 해 보기: 알을 들고 숲 밖 **길 위**로 나와서 서 있어요. (경비는 숲 밖으로도 좀 쫓아와요.)
  - 정상: 잡히면 알이 **그 자리에 떨어져요**. 다시 주울 수 있고, 아무도 안 주우면 60초 뒤에 사라져요.
  - 또 해 보기: 알을 들고 있는 동안은 숲 둥지가 비어 있고, 내가 숲을 벗어나서 30초쯤 지나면 그 둥지에 새 알이 놓여요.

- [ ] **14. 배달이 되나요?**
  - 해 보기: 알을 들고 경비를 따돌리거나(속도를 올리거나: `/speed 1e9`) 잡히지 않게 베이스로 달려가요. 베이스 안 **초록 빛나는 동그라미(배달 패드)** 위에 올라서요.
  - 정상: 알림 글자와 반짝이가 나오고, 알이 베이스의 **부화 슬롯(받침대)** 위에 놓여요. 오른쪽 "자라는 알" 칸에도 알이 생겨요.

- [ ] **15. 알이 자라고 부화하나요?**
  - 해 보기: 오른쪽 가운데 **"자라는 알"** 칸을 봐요. 남은 시간이 줄어요. 채팅에 `/grow` 를 쓰면 바로 다 자라요. **부화!** 버튼을 눌러요.
  - 정상: 알이 흔들리다가 펑! 하고 **펫 카드**가 팝업으로 떠요. 처음 만난 펫이면 빨간 **NEW!** 가 붙어요. "좋아요!" 를 누르면 닫혀요.
  - **폰 화면이면 특히 확인:** "자라는 알" 칸이 처음부터 접혀 있을 수 있어요. 제목을 눌러서 펼쳐져야 해요. (접혀 있어서 부화 버튼을 못 찾았다면 알려 주세요.)

- [ ] **16. 펫이 일하고 돈을 벌어 오나요?**
  - 해 보기: 왼쪽 **펫** 버튼 → 새 펫을 **장착**해요.
  - 정상: 베이스의 우리(나무 울타리 잔디)에 펫이 나타나서 통통 뛰어다녀요. 머리 위에 `$숫자/초` 가 보여요. **돈이 1초마다 올라요.**

### 라. 낮과 밤 (17~19번)

- [ ] **17. 밤이 오나요?**
  - 해 보기: 채팅에 `/skip` 한 번.
  - 정상: 화면이 **어두워져요**. 위쪽에 빨간 띠 "밤! 알이 30배 빨리 자라요" 가 떠요. 시계가 빨간 "밤 0:10" 이 돼요. 구역 둘레에 **빨간 반투명 벽**이 보여요.

- [ ] **18. 밤에는 알이 안 훔쳐지나요?**
  - 해 보기: 밤에 숲 알에서 E 를 눌러 봐요. (벽 때문에 구역에 못 들어가면 벽 앞까지만 가도 돼요.)
  - 정상: "밤에는 알을 훔칠 수 없어요!" 빨간 알림이 떠요.
  - 또 확인: 구역 안에서 벽에 갇히면 10초쯤 뒤에 풀려요. **오래 갇히면 알려 주세요.**
  - 또 확인: 밤에 알을 들고 있으면 **내 베이스로 순간이동**해요. (배달 가능!)

- [ ] **19. 알이 새로 바뀌나요?**
  - 해 보기: 밤에서 `/skip` 을 한 번 더 쓰고, 그다음 또 한 번 더 써요.
  - 정상: 첫 번째 `/skip` 에서 "ALL EGG RESET!" 노란 공지가 위에 떠요. 모든 둥지의 알이 새로 놓여요. 가끔 "OO 구역에 OO 알 등장!" 하는 **특별 알** 공지도 떠요. 두 번째 `/skip` 에서 낮으로 돌아오고 화면이 다시 밝아져요.

### 마. 도감과 선물 (20~21번)

- [ ] **20. 도감 보상이 되나요?**
  - 해 보기: 펫을 부화한 뒤 왼쪽 **도감** 버튼 → 새로 만난 펫 카드에 **받기!** 가 있으면 눌러요. **모두 받기** 도 눌러 봐요.
  - 정상: 속도와 돈이 늘고 반짝이는 알림이 떠요. 왼쪽 도감 버튼에 있던 빨간 숫자 배지가 사라져요.

- [ ] **21. 무료 선물이 한 번만 되나요?**
  - 해 보기: 왼쪽 **선물** 버튼 → 무료 보상을 눌러요.
  - 정상: "속도 +10,000" 알림이 뜨고, **두 번째는 안 돼요.**

### 바. 방해 도구 (22번)

- [ ] **22. 곰덫이 되나요?**
  - 해 보기: 채팅에 `/trap 5`. 오른쪽 아래 곰덫 버튼을 눌러 손에 들고, **베이스 밖 길 위**에서 한 번 더 눌러요. (베이스 안 안전 구역에서는 못 써요. 그건 정상이에요.)
  - 정상: 발밑에 곰덫이 놓이고 개수가 줄어요. 다른 사람이 밟으면 5초 동안 못 움직여요. 혼자라면 설치만 확인해도 돼요.

### 사. 2단계 특수 장소 (23~26번)

- [ ] **23. 퓨전 머신이 되나요?**
  - 해 보기: `/pet chicken 3` (닭 3마리). 내 베이스의 **보라색 기계(퓨전 머신)** 앞에서 **E**. 같은 펫 3마리를 골라서 **퓨전!** 을 눌러요.
  - 정상: 유리통이 차례로 번쩍하고 빛이 모였다가 펑! 하고 **더 센 펫 카드**가 나와요 ("희귀도 UP!" 같은 리본). 남의 베이스 기계에는 E 가 안 떠요.

- [ ] **24. 사쿠라 인큐베이터가 되나요?**
  - 해 보기: `/pet crane 1` 과 `/crystal 5`, `/speed 1e9`(빨리 가려고). 길을 따라 멀리 가서 **벚꽃 구역(10번째)** 의 분홍 나무 인큐베이터에서 **E**. 처음엔 "학 바치기", 열린 뒤에는 "꽃피우기".
  - 정상: 해금 배너와 꽃잎이 날려요. 나중에 알이나 펫에 **블룸**을 걸 수 있어요.
  - (멀어요! 오래 걸으면 힘드니 `/speed 1e9` 를 꼭 쓰세요.)

- [ ] **25. 마법의 숲 퀘스트가 되나요?**
  - 해 보기: 채팅에 `/quests`. 왼쪽 메뉴 맨 아래 **퀘스트** 를 눌러요.
  - 정상: 3줄이 전부 "완료"로 바뀌고, 마법의 숲(13번째 구역) 뒤쪽 **돌 문이 열려요**.

- [ ] **26. (어른과 둘이서) 제단과 비밀 통로가 되나요?**
  - 해 보기: 스튜디오 위쪽 **Test(테스트)** 탭에서 플레이어 2명으로 시작해요. 천사&악마 구역(12번째)의 **천국 제단**과 **지옥 제단**에 두 사람이 각각 펫을 바쳐요. 이어서 폭포 옆 **비밀 통로**에서 `/pet pegasus 1`, `/pet skeleton_horse 1` 로 합성해요.
  - 정상: 제단 위에 "기다리는 중 (1/2)" → "짝 성공! (2/2)" 가 뜨고 특별 알 카드가 나와요. 비밀 통로 합성 뒤에는 "이미 사용함" 이 돼요.
  - 어려우면 이 항목은 건너뛰어도 돼요.

### 아. 폰, 속도, 저장, 소리 (27~30번)

- [ ] **27. 폰 화면에서도 괜찮나요?**
  - 해 보기: 스튜디오 **Test(테스트)** 탭의 장치 에뮬레이터에서 폰 모양(가로)을 골라요.
  - 정상: 왼쪽 6개 버튼이 화면 안에 다 보여요. 버튼이 **손가락으로 누르기 충분히 커요**. 오른쪽 아래 도구 버튼이 점프 버튼과 **안 겹쳐요**. 창이 화면 밖으로 안 삐져나가요.

- [ ] **28. 끊기지 않나요?**
  - 해 보기: 구역 사이를 빠르게 달려 봐요. 많은 동물 근처에서도 달려요.
  - 정상: 움직임이 부드러워요. **심하게 끊기면** 어느 구역에서 끊겼는지 알려 주세요. (맵에 부품이 1만 개가 넘어서 폰이 힘들 수 있어요.)

- [ ] **29. 저장이 되나요?** (선택)
  - 해 보기: 돈을 모은 뒤 **Stop(정지)** → 다시 **Play**. 돈이 남아 있는지 봐요.
  - 정상: 게임을 **게시하고 "Studio에서 API 서비스 접근 허용"** 을 켠 경우에만 남아요. 안 켰으면 돈이 사라지는 게 **정상**이에요 ("메모리 모드"). 켰는데도 사라지면 알려 주세요.

- [ ] **30. 소리는요?**
  - 정상: 아직 **소리가 하나도 안 나는 게 맞아요.** 소리 번호(ID)를 아직 안 넣었어요. 나중에 사장님이 `Sounds.luau` 의 `rbxassetid://0` 자리에 소리 번호를 넣으면 나요.
  - 설정 창의 음악/효과음 끄기 버튼은 눌러져야 해요.

## 4부. 고장 보고 방법 (이상한 걸 찾았을 때)

찾으면 **본부장에게 이 틀 그대로** 채워서 보내 주세요. 다 못 채워도 괜찮아요. 아는 것만요.

```
번호: (위의 몇 번 항목이에요? 예: 11번)
무엇을 했나요: (예: 숲에서 알을 들고 가만히 서 있었어요)
어떻게 됐나요: (예: 경비가 안 움직이고 땅에 박혀 있어요)
원래는 어떻게 돼야 하나요: (예: 경비가 걸어와야 해요)
몇 번 해 봤나요: (예: 3번 다 똑같았어요 / 한 번만 그랬어요)
```

그리고 **같이 보내 주면 아주 큰 도움이 되는 것 3가지:**

1. **화면 사진.** 키보드 **Windows + Shift + S** 를 누르고 부분을 끌어서 고르면 복사돼요. 대화창에 **붙여넣기(Ctrl + V)** 하면 돼요.
2. **글자 창(Output)의 빨간 글자.** Output 창에서 마우스 오른쪽 버튼 → **Select All(모두 선택)** → 다시 오른쪽 버튼 → **Copy(복사)**. 대화창에 **붙여넣기** 해요. 빨간 글자가 없어도 "빨간 글자 없음" 이라고 적어 주세요.
3. **컴퓨터인지 폰 에뮬레이터인지.** (폰 모양으로 시험했다면 알려 주세요.)

> 고장은 나쁜 게 아니에요. 사장님이 찾아 주면 고칠 수 있어서 게임이 더 좋아져요. 고마워요!
