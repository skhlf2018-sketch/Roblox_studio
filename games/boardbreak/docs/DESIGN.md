# 송판 깨기 (Board Break) — 설계서 1판

사장님 지시 2026-11-16. 두 번째 게임. **우리 팀이 처음부터 만드는 게임** (다른 게임의 이름·캐릭터·그림·맵을 따라 하지 않는다).
코드는 `games/boardbreak/` 아래 (`src/shared` · `src/server` · `src/client` · `tests` · `docs`), 빌드는 `build/BoardBreak.rbxl`.
첫 번째 게임(`src/`, `tests/`)의 구조·도구·테스트 방식을 그대로 따른다 (필요한 공통 파일은 **복사**해서 쓴다 — 첫 게임 파일은 고치지 않는다).

## 1. 사장님이 정한 것 (바꾸지 말 것)

1. **힘은 아령으로 올린다.** 아령은 돈으로 더 좋은 것을 산다.
2. **물건을 깨면 돈을 받는다.** 값: 솜 3 · 유리 10 · 플라스틱 20 · 나무 50 · 철 128 · 강철 256 · 고무 1,024 · 컴퓨터 8,192 · 핸드폰 32,768 · 육교 524,288 · 아파트 1,000,000 … 그 뒤로 30개 더. 나중에는 행성이 하나씩 나오고 태양계·블랙홀도 나온다.
3. **돈 단위**: K < M < B < T < Qa < Qi < Sx < Sp < Oc < No < Dc … (`Format.number`)
4. **로벅스**: 힘 2배 영구 · 4배 · 8배 … 2048배, 돈 2배 영구 199 로벅스.
5. **띠**가 있다.
6. **마지막에는 시험관과 대결**한다.
7. **월드 3개**까지 (일단).
8. 나머지는 본부장이 정한다 (아래 2~7장. [본부장] 표시).

## 2. 놀이 순서 [본부장]

1. 도장에서 아령을 든다 → 누를 때마다(또는 누르고 있으면) **힘 +** (아령이 좋을수록 많이).
2. 물건 앞에 가서 친다 → 한 번 칠 때 물건 체력이 **내 힘만큼** 깎인다 → 0 이 되면 깨지고 **돈**을 받는다. 물건은 금방 다시 생긴다 (플레이어마다 따로 — 남이 깨도 내 물건은 그대로).
3. 돈으로 더 좋은 아령을 산다 → 힘이 더 빨리 오른다 → 더 비싼 물건을 깬다.
4. 힘이 모이면 **승급 심사**를 봐서 띠를 올린다 (띠 = 돈 배율 + 다음 물건 열림).
5. 월드의 마지막 띠는 **시험관과 대결**해서 이겨야 받는다 → 다음 월드가 열린다.
6. 월드 3의 마지막 시험관을 이기면 "그랜드 마스터" (엔딩. 그 뒤에도 계속 깰 수 있음).

물건은 **깰 수 있는 힘**(`minPower`)이 안 되면 "힘이 부족해요"만 나온다 (체력이 안 깎임).

## 4. 아령 · 띠 · 시험관 [본부장 — 숫자는 수석이 6장 규칙으로 확정]

- **아령 20개** (1kg 아령 → … → 블랙홀 아령). 순서대로만 산다. `powerPerRep`(한 번 들 때 오르는 힘)와 `price`.
- **띠 12개**: 월드 1 = 흰 · 노랑 · 초록 · 파랑 / 월드 2 = 보라 · 갈색 · 빨강 · 검정 / 월드 3 = 1단 · 3단 · 6단 · 9단(그랜드 마스터).
  띠마다 `moneyMultiplier`(깬 돈 배율)와 승급 조건 `needPower`. 각 월드의 **네 번째 띠**는 시험관 대결로만 받는다.
- **승급 심사** (시험관 대결이 아닌 띠): 도장의 심사대에서 시작 → **20초 안에 송판 10장** (체력은 그 띠에 맞게)을 다 깨면 합격. 떨어져도 벌칙 없음 (바로 다시 가능).
- **시험관 대결** (월드마다 1명, 3명): 나와 시험관이 나란히 **송판 15장**을 깬다. 시험관은 정해진 속도로 깬다 (플레이어 힘과 무관 — 그 월드 마지막 물건을 깰 수 있는 힘이면 넉넉히 이기는 정도). **먼저 다 깨면 승리.** 이기면 띠 + 다음 월드. 지면 다시 도전.
  서버가 판정한다 (클라가 "이겼다"고 보내는 Remote 없음).

## 5. 로벅스 상품 [사장님 + 본부장]

| key | 종류 | 효과 | 로벅스 |
|---|---|---|---|
| `power_2` … `power_2048` (11개) | 게임패스 (영구) | 힘 N배 — **아령으로 오르는 힘**과 **칠 때 깎는 힘** 둘 다 [본부장] | N [본부장 추정: 첫 게임과 같이 배수 = 가격] |
| `money_2` | 게임패스 (영구) | 깬 돈 2배 | 199 [사장님] |

- 힘 배수는 **순서대로만 열림** (2배를 사야 4배) — 첫 게임 규칙 그대로 (`boostFromOwnedPasses` 방식, 곱이 아니라 가장 큰 것 하나).
- id 는 전부 0 (게임을 게시한 뒤 어른과 함께 만든다) → 화면은 "준비 중". 개발 명령 `/buy <key>` 로 시험.
- 지급·영수증·패스 소유 확인 방식은 첫 게임 `ProductService` 를 그대로 가져온다.

## 6. 숫자 규칙 (수석이 표를 만들고 시뮬레이션으로 증명) [본부장]

- 첫 물건(솜)은 시작하고 **30초 안에** 깬다. 처음 5분 안에 아령을 2번 이상 바꾼다.
- 물건 N 을 편하게 깨기 시작한 뒤 물건 N+1 을 깰 수 있게 되기까지 **1~4분** (열심히 하는 플레이어, 로벅스 없음).
- 월드 1 끝 ≈ 40분 · 월드 2 끝 ≈ 2시간 30분 · 월드 3 끝 ≈ 6시간 (±30%). `tests/sim_progress.luau` 가 이 숫자를 출력·검사.
- 물건 한 개를 깨는 데 드는 타격 수: 막 열렸을 때 15~30번, 익숙해지면 1~3번.
- 속도 제한 (서버): 아령 들기 초당 5번, 치기 초당 5번까지. 넘는 요청은 버림.
- 수의 범위: 힘·돈은 1e60 까지 터지지 않게 (NaN·무한 방어, `Format` 단위는 그 범위까지).
- 2048배 패스를 사도 띠·시험관·월드 순서는 건너뛸 수 없다 (빨라질 뿐).

## 7. 계약 (수석 = 데이터·서버, 선임 = 맵·화면. 서로 이 이름으로 맞춘다)

**데이터 모듈** (`src/shared/Data/`, 수석): `Config` · `Targets`(list, get, byWorld) · `Dumbbells` · `Belts` · `Worlds`(3개: id·이름·테마색·시험관 이름) · `Products` · `Sounds`(선임).
`Targets` 항목: `{ id, index, name, world, reward, hp, minPower }`.

**플레이어 Attribute** (서버가 씀): `Power` · `Money` · `DumbbellLevel` · `Belt`(1~12) · `World`(열린 월드 1~3) · `CurrentWorld`(지금 있는 월드) · `PowerBoost`(1, 2 … 2048) · `MoneyPass`(bool) · `DataLoaded` · `SaveEnabled`.

**Remote (클라 → 서버)**: `ClientReady()` · `Train()` (아령 1번) · `Hit(targetId)` · `BuyDumbbell()` (다음 아령) · `StartExam()` · `StartDuel()` · `Travel(worldIndex)` · `SetSetting(key, value)`.
**Remote (서버 → 클라)**: `Snapshot(data)` · `DataUpdate(section, payload)` · `Notify { kind, text }` · `TrainResult { gain, power }` · `HitResult { targetId, damage, hp, hpMax, broken, reward?, reason? }` · `ExamState { phase = "start"|"progress"|"pass"|"fail", broken, total, secondsLeft, belt, boardHp?, boardHpMax? }` · `DuelState { phase = "start"|"progress"|"win"|"lose", mine, theirs, total, world, secondsLeft?, boardHp?, boardHpMax?, examiner? }` · `ProductGranted { key, kind }` · `LeaderboardUpdate { power, money }`.

**수석이 정한 것 (1판 계약 보충 — 이름은 `src/shared/Remotes.luau` · `Tags.luau` · `Types.luau` 가 기준)**:
- **심사·대결 송판 치기 = 같은 `Hit` Remote**: 심사 중에는 `Hit("exam")`, 대결 중에는 `Hit("duel")` (`Remotes.EXAM_TARGET` · `DUEL_TARGET`). 일반 치기와 같은 속도 제한(초당 5번). 심사대·대결장 근처에서만 셈. 시작은 `StartExam()` · `StartDuel()` (심사대 `MapLayout.examPad` 30 스터드 · 대결장 `duelArena` 40 스터드 안). 대결은 `"start"` 뒤 3초 카운트다운 후 시작 (그동안 친 것은 무시). 심사·대결 중에는 `Travel` 안 됨.
- `Notify` 는 첫 게임처럼 **표 하나** `{ kind, text }` 로 보냄 (kind = `"info"` | `"success"` | `"error"`).
- `HitResult.reason = "weak"` → "힘이 부족해요" (피해 0). 없는 id · 닫힌 월드 · 너무 먼 거리(`targetReach(id)` + 6)는 **아무것도 안 보냄** (무시).
- **"치는 힘" = Power × PowerBoost** — 물건을 깰 수 있나(minPower)도 이 값으로 봄. 띠 승급(needPower)은 저장된 힘 `Power` 로 봄.
- 띠는 **돈 배율**. 다음 물건은 힘(minPower)으로 열리고, 각 월드의 네 번째 띠(대결)가 다음 월드(새 물건들)를 엶 (띠 4 → 월드 2, 띠 8 → 월드 3, 띠 12 = 그랜드 마스터).
- `DataUpdate` 섹션: `"stats"` { power, money } · `"progress"` { dumbbellLevel, belt, world, broken, grandMaster } · `"passes"` { powerBoost, moneyPass, ownedPasses } · `"settings"` { settings }. 들기·치기마다 보내지 않음 (힘·돈은 Attribute 로).
- 플레이어 Attribute 추가: `Activity` (`""` | `"exam"` | `"duel"`) · `GrandMaster` (bool).
- 태그 추가: `TrainMat` (수련 매트) · `WorldSpawn`. 파트 Attribute: `TargetId` · `World` · `TargetWorld`(문이 가는 월드).
- `SetSetting` 키 (전부 boolean): `music` · `sfx` · `lowGraphics`.
- "들기"·"치기" 버튼을 누르고 있으면 **0.25초마다** 반복 (초당 4번 — 서버 한도 5번 아래, 시뮬레이션도 초당 4번).
- 접속하면 열린 가장 높은 월드 스폰에서 시작. 캐릭터가 다시 생기면 지금 월드 스폰으로 (서버가 옮김).
- 아령 가게는 메뉴에서 바로 삼 (자리 확인 없음).

**맵** (선임 `MapBuilder`, 자리는 수석 `MapLayout`): 월드마다 로비(도장) + 물건 자리. 물건 모델은 `CollectionService` 태그 `BreakTarget`, Attribute `TargetId`. 물건을 치는 방법 = 물건을 **클릭/탭** (ClickDetector) 또는 가까이서 화면의 큰 "치기" 버튼 — 회색 E 프롬프트는 쓰지 않는다 (사장님은 표지판·물건을 직접 누르는 것을 좋아함).
아령 들기 = 도장의 **수련 매트** 위에서 화면을 누르거나 "들기" 버튼 (누르고 있으면 자동 반복).
월드 이동 = 로비의 문(열린 월드만). 심사대 `ExamPad` · 대결장 `DuelArena` · 아령 가게 `DumbbellShop` · 띠 표지판 `BeltBoard`(12개 띠와 지금 내 띠).

**화면** (선임): 왼쪽 아래 힘·돈, 지금 띠, 왼쪽 메뉴(아령 가게 · 도감(깬 물건) · 힘 배수 · 설정), 물건 위 체력 막대와 값, 깨질 때 조각 + 돈 숫자, 심사·대결 화면(내 송판/시험관 송판 진행 막대, 남은 시간), 처음 하는 사람을 위한 화살표 안내 3단계 (아령 들기 → 솜 깨기 → 아령 사기). 폰에서도 버튼이 손가락으로 눌린다.

**저장** (수석): `power` · `money` · `dumbbellLevel` · `belt` · `world` · `broken`(물건별 깬 횟수) · `powerBoost` · `moneyPass` · `receipts` · `stats` · `settings` · 스키마 1. DataStore 이름은 첫 게임과 다르게 (`BoardBreak_PlayerData`).

**개발 명령** (스튜디오만): `/power <n>` · `/money <n>` · `/belt <1-12>` · `/world <1-3>` · `/dumbbell <1-20>` · `/buy <key>` · `/unbuy` · `/reset`.
(수석: `/power` · `/money` 는 그 값으로 **정함**. `/belt` 는 열린 월드도 띠에 맞춤. `/world n` 은 띠가 모자라면 그 월드 첫 띠로 올리고 순간이동.)

## 9. 숫자 표 (수석 — `tests/sim_progress.luau` 로 증명)

**어떻게 정했나** — 6장 규칙을 다 지키도록 "열심히 하는 플레이어"(10초 들기 초당 4번 → 2초 걷기 → 10초 치기 초당 4번 → 2초 걷기 반복, 살 수 있는 아령은 바로 삼, 심사·대결은 되자마자, 로벅스 없음)를 흉내 내며 숫자를 만들었습니다.
- 물건: 막 열렸을 때 15~19번 (`hp ≈ minPower × 15` · 월드 3 은 × 18). 다음 물건의 minPower = 지금 물건이 "3번 안에 깨지는" 힘이 된 뒤 66초(월드 1) · 78초(월드 2) · 90초(월드 3) 지난 힘.
- 아령: 한 번 들 때 힘이 앞 아령의 100배 (달 아령 · 초신성 아령은 1000배 — 오래 걸린 물건 바로 뒤라서). 값 = 그때까지 모은 돈. 아령을 사면 지금 물건이 금방 쉬워지고, 그 다음 물건은 조금 오래 걸리는 리듬.
- 띠: 심사 띠 needPower = 그 물건이 열릴 때의 힘 (빨강 띠 · 6단 띠는 오래 걸리는 물건 한가운데에 — 기다리는 동안 할 일). 대결 띠 = 마지막 물건이 편해지고 85~120초 뒤 힘. 심사 송판 = needPower × 4 (10장 × 4번 = 10초 < 20초), 대결 송판 = needPower × 3 (15장 × 3번 ≈ 11초 + 카운트다운 3초 < 시험관 18~24초).
- 띠 돈 배율: 1 · 1.5 · 2 · 3 / 5 · 8 · 12 · 20 / 35 · 60 · 100 · 200.
