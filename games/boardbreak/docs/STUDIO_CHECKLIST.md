# 송판 깨기 — 스튜디오에서 눈으로 볼 것 (선임)

`build/BoardBreak.rbxl` 을 열고 ▶ 플레이. 개발 명령: `/power 1e9` · `/money 1e9` · `/belt 4` · `/world 3` · `/buy power_2`.
폰은 스튜디오 **기기 에뮬레이터**(iPhone 가로)로도 한 번씩.

## 맵
1. 스폰하면 월드 1 도장 안 (나무 바닥, 하얀 벽, 빨간 기둥). 스폰 위를 표지판이 가리지 않는다.
2. 수련 매트 6칸(왼쪽)이 잘 보이고, 매트 위 글 "💪 수련 매트" 가 읽힌다.
3. 아령 가게(오른쪽 뒤): 카운터·진열장의 아령 60개가 공중에 뜨거나 벽에 박히지 않았다.
4. 띠 표지판(오른쪽 벽): 12칸 글자가 잘리지 않고, 지금 내 띠 칸이 초록 테두리.
5. 심사대(오른쪽 앞) 송판 10장 · 대결장(왼쪽 앞) 송판 15장 × 2줄 · 시험관 NPC(도복 + 띠, 이름표)가 제자리.
6. 뒤쪽 문 2개: 잠긴 문에 자물쇠, `/world 3` 뒤에는 자물쇠가 사라진다.
7. 정문 밖 길 양옆 물건 13개(월드 1): 솜(흰 뭉치) · 유리(반투명 판) · 나무 송판 · 타이어(고무) · 컴퓨터 · 핸드폰 · 육교 · 아파트 … 이름표(이름·💰·💪)가 겹치지 않는다.
8. 월드 2 (`/world 2` 뒤 문으로): 도시 빌딩·바다·산 장식, 피라미드·화산·섬 등이 서로·길과 안 겹친다.
9. 월드 3: 검은 바닥 + 별, 밤하늘 조명, 행성들이 떠 있는 받침대 위. 토성 고리·블랙홀 원반이 길을 막지 않는다.

## 조작
10. 매트에 서면 큰 빨간 "들기" 버튼 + 손에 아령. 누르고 있으면 계속 들리고 "+N 💪" 가 떠오른다. 매트에서 내려오면 사라진다.
11. 솜을 마우스로 누르면 치고, 멀리 있는 물건을 누르면 그 앞으로 걸어가서 친다.
12. 물건 가까이 서면 주황 "치기" 버튼 (물건 이름 표시). 체력 막대가 줄고, 깨지면 조각이 튀고 "+💰 3" 이 뜬다.
13. 힘이 모자란 물건(유리 등)을 치면 물건 위에 빨간 "힘이 부족해요!" (토스트는 안 뜸).
14. 아령 가게 카운터를 누르면 가게 창, 사기 → 돈이 줄고 다음 아령. 돈이 모자라면 회색.
15. 띠 창 "심사 보기" → 심사대로 걸어가서 시작, 위 패널(송판 막대·시간)이 움직이고 도장 송판이 하나씩 사라진다. 합격 큰 글.
16. `/belt 3` + `/power 1e17` → "시험관과 대결" → 3·2·1, 막대 2개(나 / 시험관), 이기면 다음 월드 문 배너.
17. 힘 배수 창: 2배만 초록, 4배부터 🔒. 누르면 "준비 중" 토스트 (id 0).

## 폰 (기기 에뮬레이터)
18. 힘·돈·띠 줄이 위 왼쪽, 메뉴 버튼이 조이스틱 위, "들기"/"치기" 버튼이 점프 버튼 위 — 서로 안 겹치고 손가락으로 눌린다.
19. 창(가게·도감·띠)이 화면 안에 다 들어오고 닫기 X 가 눌린다.

## 소리
20. 버튼 톡 · 치기 퍽 · 깨짐 와장창 · 월드별 배경음이 나오고, 설정에서 끄면 꺼진다 (안 나는 소리 id 는 `Data/Sounds.luau` 에서 교체).

## 2026-11-16 겉모습 고침 (아바타 아령 · 천장 · 사범님 · 금 · 아우라)
21. 수련 매트 위: 내 아바타 오른손에 아령이 **손바닥에 쥔 채** 붙어 있다 (바닥에 떨어진 조각 없음). 1번은 회색 손잡이 + 검은 원판 2겹(무료 모델 Dumbell 모양). 리스폰·아바타 늦게 로딩 뒤에도 다시 붙는다.
22. "들기"를 누르고 있으면 팔이 아래 → 가슴 → 머리 위로 0.25초마다 올라갔다 내려간다. 걷기 애니메이션과 안 싸운다. 무거운 아령(표 절반부터)은 두 손에 하나씩. 다른 플레이어 화면(2명 테스트)에서도 같은 동작이 보인다.
23. 길가 매트 위에서 물건을 누르면 치기만 나가고 팔은 안 든다. 빈 땅을 누르면 든다.
24. 도장 3곳에 천장: 1 기와지붕 · 2 유리 돔 체육관 · 3 보라 우주선 돔. 안이 밝고, 카메라가 천장에 끼지 않으며, 정문·월드 문을 그대로 지나다닌다.
25. 대결장 사범님: 사람 몸(R15)에 흰 도복·깃·띠 매듭·머리카락·얼굴, 이름표. 1 검은 띠 · 2 빨간 깃/소매 · 3 금색 띠. 플레이어를 막지 않는다. 대결 중 사범님이 송판을 깰 때마다 오른팔을 내리친다. (출력 창에 R15 실패 경고가 없으면 블록 대체가 아님)
26. 물건·심사·대결 송판을 칠 때 체력 75·50·25% 에서 금이 한 단계씩 늘고 조각이 톡 떨어진다. 깨지면 금이 사라진다. "힘이 부족해요" 글은 더 안 뜨고, 물건 위 "💪 추천 힘 N" 이 내 힘이 모자라면 주황색.
27. 띠 창: 힘이 약해도 "심사 보기"/"대결" 버튼이 눌린다 (아래에 "추천 힘 N — 지금은 어려울 수 있어요").
28. 아우라: 힘 100 부터 몸 둘레에 흰 빛 알갱이 + 발밑 고리, 자릿수가 오를 때마다 색이 바뀌고 "✨ 아우라 UP!" 번쩍. 설정 저사양이면 남의 아우라 알갱이가 꺼진다. 무거운 아령은 테두리가 빛나고 알갱이·번개 줄.
