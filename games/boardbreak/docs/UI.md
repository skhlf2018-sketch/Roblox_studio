# 송판 깨기 — 화면 목록 (선임)

**말투 규칙 (사장님 2026-11-16 · 앞으로 쓰는 글도 전부)**
1. 존댓말·해요체 금지 — 글 끝에 "~요 / ~세요 / ~습니다 / ~해요 / ~돼요 / ~예요" 안 씀. 반말 명령("~해라")도 안 씀.
2. 명사형·짧은 지시형 — "~하기", "~ 구매", "~ 필요", "~ 부족", "~ 가능", "~ 완료", "~ 실패", "~ 열림", 또는 한마디("합격!", "승리!").
3. 짧게 — 안내 한 줄 20자 안팎, 버튼 2~4자. 버튼 이름은 [들기]·[치기] 처럼 대괄호로 가리킴.
4. 이모지는 앞에 하나까지, 느낌표는 한 문장에 하나까지.
5. 숫자·단위·이름(물건·아령·띠·월드·사범님)은 그대로. 서버 알림(`Net.notify`)·맵 표지판·개발 명령 안내도 같은 규칙.

코드: `src/client/` (진입점 `Main.client.luau` → 컨트롤러마다 `start()`). 공통 도구는 첫 게임에서 복사:
`UI/Ui.luau`(위젯·창·배율) · `UI/Theme.luau`(색) · `UI/Icons.luau`(Frame 그림) · `UI/Windows.luau`(창은 한 번에 하나, ESC 로 닫힘)
· `UI/Layout.luau`(자리 계산, 숫자만) · `Purchase.luau`(로벅스 구매창) · `Net.luau` · `State.luau`.
새로 만든 것: `UI/ActionButton.luau`(큰 둥근 버튼, 누르고 있으면 0.25초마다) · `Walk.luau`(내 캐릭터 거리·걸어가기).

기준 화면 1100×720. `Ui.scaled` 가 화면에 맞춰 줄이고 늘림. 손가락 버튼은 화면에서 **46px 이상** (`Ui.touch`, `Layout.MIN_TOUCH`).

## 1. 늘 보이는 화면 (HudController)

| 자리 | 내용 |
|---|---|
| 왼쪽 아래 (PC) / 위 왼쪽 한 줄 (터치) | 💪 힘 (빨강) + 힘 배수 배지 `×8` · 💰 돈 (금색) · 지금 띠 (색 띠 + 이름). 숫자는 `Format.number` |
| 왼쪽 가운데 | 메뉴 버튼 5개: 아령 가게(1) · 도감(2) · 힘 배수(3) · 띠·심사(4) · 설정(5). 터치는 조이스틱 위·힘 줄 아래, 1열이 안 되면 2열 |
| 아래 가운데 (PC) / 오른쪽 점프 버튼 위 (터치) | 큰 버튼 "들기"(TrainController, 수련 매트 위에서만) · "치기"(BreakController, 물건 가까이·심사·대결 중) |
| 위 가운데 | 튜토리얼 패널 (TutorialController) · 심사·대결 패널 (ExamController — 둘이 같이 안 나옴) |
| 아래 가운데 | 토스트 (서버 Notify) · 위쪽 큰 배너 (월드 이동·문 열림) |

## 2. 창 (Windows — 한 번에 하나)

| 이름 | 열기 | 내용 |
|---|---|---|
| `DumbbellShop` 아령 가게 | 메뉴 · 도장 아령 가게를 누름 | 지금 아령 → 다음 아령 (이름·가격·한 번에 +힘), 사기 버튼 → `BuyDumbbell()`. 돈 모자라면 회색 "💰 N 더 필요해요". 아래 20개 목록 |
| `Index` 도감 | 메뉴 | 물건 41개 (월드별). 깬 것 = 이름·★·깬 횟수, 안 깬 것 = "???"·물음표. 위 "깬 물건 N / 41" |
| `BoostWindow` 힘 배수 | 메뉴 | 힘 배수 11장(2배 … 2048배) + 돈 2배 1장. 순서대로만 열림 (회색 🔒 "2배를 먼저 사요"), id 0 이면 "준비 중" |
| `Belts` 띠·승급 심사 | 메뉴 · 띠 표지판 · 심사대 · 대결장을 누름 | 띠 12개 (지금 띠 ✔), 다음 띠 조건, "🥋 심사 보기" → `StartExam()` / "⚔️ 시험관과 대결" → `StartDuel()` (멀면 걸어가서) |
| `Settings` 설정 | 메뉴 | 음악 · 효과음 · 그래픽 줄이기 → `SetSetting(key, bool)` |

## 3. 월드에서 직접 누르기 (ClickDetector "Click" — 회색 E 프롬프트 없음)

| 무엇 | 누르면 |
|---|---|
| 물건 (태그 `BreakTarget`) | 가까우면 `Hit(id)`, 멀면 앞길로 걸어가서 `Hit(id)` |
| 아령 가게 (`DumbbellShop`) | 아령 가게 창 |
| 띠 표지판 · 심사대 · 대결장 | 띠 창 |
| 월드 문 (`WorldDoor`) | 열렸으면 화면이 까매졌다가 `Travel(n)`, 잠겼으면 "🔒 시험관을 이기면 열려요" |
| 수련 매트 위에서 화면 아무 곳 | `Train()` 한 번 |

## 4. 서버 → 화면

| Remote | 화면 |
|---|---|
| `Snapshot` · `DataUpdate` | State 에 합침 → HUD·창 다시 그림 (힘·돈은 플레이어 Attribute 를 먼저 읽음) |
| `TrainResult` | 머리 위 "+N 💪" · 손의 아령이 번쩍 |
| `HitResult` | 물건 위 체력 막대(4초) · "-N" · 흔들림 · 깨지면 조각 + "+💰N" + 잠깐 사라졌다 다시 · weak → 빨간 "힘이 부족해요! (💪 N 필요)" |
| `ExamState` | 심사 패널: 막대 1 깬 송판 · 막대 2 남은 시간 · 송판 체력, 도장 송판 Board_1..10 이 깬 만큼 사라짐, 합격/불합격 큰 글 |
| `DuelState` | 대결 패널: 막대 1 나 · 막대 2 시험관 · 남은 시간, 3·2·1 시작, Mine_/Theirs_ 송판 사라짐, 승리/패배 큰 글 |
| `Notify` | 토스트 ("힘이 부족해요…" 는 물건 위 빨간 글이 대신이라 안 띄움) |
| `ProductGranted` | 팡파레 + "🎉 ○○ 받았어요!" (Purchase) |

## 5. 튜토리얼 (TutorialController, 월드 1 에서만)

1/3 수련 매트에서 들기 (힘 10) → 2/3 솜 깨기 → 3/3 다음 아령 사기. 단계는 저장된 값(힘·깬 횟수·아령)으로 정함.
노란 화살표가 목표 위에서 통통 튐 (내 화면에만 있는 파트).

## 6. 소리 (`src/shared/Data/Sounds.luau`)

첫 게임에서 확인된 무료 id 를 다시 씀. `Tick` 은 0 (본부장이 스튜디오에서 채움). 월드마다 배경음, 심사·대결 중 긴장 음악.
